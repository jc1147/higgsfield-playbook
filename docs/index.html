At scale on fal: rejected

The first AK Sacramento set was 60 images on fal Nano Banana Pro (~$12.39). We rejected it: half bodies, a pillow standing in for a back, a stock look. Our own audit then failed 11 of 47 photos and 8 of 13 illustration plates (4 lumbar vertebrae instead of 5, a nerve drawn over a ligament instead of under it).

At scale on Higgsfield: shipped after review

The second set ran on Higgsfield Flare with a much harder brief: a glowing anatomy overlay inside each patient and a red glow at the pain site. The first pass failed 24 of 45 photos (20 overlay errors, 13 hand or body errors). Three review-and-fix rounds brought it to 57 images: 19 pass, 38 with minor notes, 0 failed. Our verdict on the look: "let's go this direction". See the set.

What that means

Flare follows a brief far better, and that's what we pay for. No model gets hands, feet and anatomy right every time, so review is part of the job, not an extra. Budget the review time: an independent zoomed check takes 60–90 minutes per 8 images.

05

How we get shippable output

What turned "AI images" into images a client accepts.

Review before anyone sees it

  • An independent reviewer checks every image zoomed in: counts the fingers on every hand and the toes on every foot, checks every body is whole, checks anatomy is placed and oriented correctly, and looks for text.
  • It takes 60–90 minutes per 8 images. Tell the client up front and run batches in parallel.
  • Record every verdict, pick and overruled point with its reason, so the set can be rebuilt and audited.
  • Check the final crops, not just the renders: a 3:2 render cropped to 7:5 lost a patient's head and toes.

Prompt rules that worked

  • Exact copy only: "Render only the following text, exactly as written, and no other words", followed by the lines in quotes.
  • Counts, spelled out: "exactly five lumbar vertebrae", "exactly N bullets and no others", "the nerve passes UNDER the band".
  • Say who is in the scene and who isn't ("one clinician in a white shirt, head out of frame; no receptionist"), and for empty scenes say "no people, no hands".
  • Face-down patients: shoot from the foot end. Seen side-on, the model draws the spine across the body.
  • One foot in side view, never two soles to camera (six toes, four toes, upside-down bones).
  • Dark work: lead with "the entire background is near-black … never light, cream or beige".
  • Colours in words, never hex codes (an app-icon run painted the hex codes as text).
  • When a model keeps painting text on a surface, remove the surface from the prompt.

House rules

  • Generate textless images; put text, logos, prices and CTAs in HTML or composite them afterwards.
  • No AI-invented logos, photo-realistic UI mockups or product renders. Product ads start from the real product photo.
  • Download and store every image in the project; provider URLs expire.
  • Compress for mobile before publishing (canvas quality 0.76 took a 484 KB image to 163 KB).
  • If the client likes an image, edit that image; don't regenerate from an earlier draft.
  • Anchor the look to an image the client has approved before producing a full set.

07

Tools & access

Higgsfield project

The toolkit is this page's repo: github.com/jc1147/higgsfield-playbook. Run npm install once.

npm run image -- --model flare --prompt "…" --aspect-ratio 3:2
npm run image -- --model flare --image product.png --prompt "…"
npm run graphic-ads -- --model flare --image product.png --prompt "…"
npm run presets            # live preset catalog with cover images
npm run image -- … --estimate   # free price quote, no render

Batch runner: hf-batch.mts in the AK Sacramento repo. It makes one request per job with no retries, saves each render's quote and request ID, and skips finished outputs.

Logo and "21+" overlays: tools/logo-cutout.ps1, tools/composite-logo.ps1.

fal

Client-site image generator (flux/dev, idempotent, dry-run prints the cost):

node generate-images.mjs <buildDir> --dry-run   # internal site builder

Batch with reference images: fal-batch.mjs. Price lookup: falprice.mjs (fal pricing API).

Also available inside Claude Code through the fal MCP server.

Keys and billing

  • Higgsfield key: HF_CREDENTIALS in a git-ignored .env.local (copy .env.example). True spend, limits and keys: console.higgsfield.ai.
  • fal key: FAL_KEY in your environment or MCP config, never in a repo.
  • Keep keys out of documents, screenshots and logs.
